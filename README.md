# Project Treasure: The Lost Cipher

Run in VS Code:
1. File > Open Folder... and choose this folder.
2. Install the "Live Server" extension (Ritwick Dey).
3. Right-click index.html > Open with Live Server.

Or run `npx serve` / `python3 -m http.server` in this folder and open the URL.
Needs internet once per load (Three.js r128 comes from cdnjs).
